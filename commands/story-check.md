---
description: Check a video script or shot list against the storytelling checklist and suggest fixes
argument-hint: "[path to script, shot list or beat sheet]"
---

Load the `video-storytelling` skill, then read the script, shot list or beat sheet at: $ARGUMENTS
(If no path is given, look for the most likely script file in the current project and say which one you used.)

1. Answer the seven story questions from Pass 1 (question, person, stakes, plant, turn, clock, payoff) from the script as written. Mark any that are missing.
2. Run the Story check list. For every unchecked item, quote the lines involved and write the specific fix: a new line, a moved beat, a hold, or an extra cut.
3. Find the longest stretch where every line has exactly one picture, and propose cuts for it.
4. Find each jump in time or place that has no bridge line, and write one.
5. End with the three changes that would do the most for tension, in order.

Don't rewrite the whole script unless asked. Keep the author's voice: short, plain sentences.
